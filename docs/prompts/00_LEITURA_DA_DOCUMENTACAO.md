# OBJETIVO

Antes de iniciar qualquer implementação, você deverá estudar completamente toda a documentação deste repositório.

O objetivo desta etapa NÃO é desenvolver nenhuma funcionalidade.

O objetivo é compreender integralmente a arquitetura, os processos da empresa, as regras de negócio e a filosofia do projeto.

Você deverá considerar esta etapa como uma fase obrigatória de aprendizado.

---

# IMPORTANTE

Nesta etapa você NÃO deverá:

- criar telas;
- escrever código;
- modificar arquivos;
- sugerir novas funcionalidades;
- alterar arquitetura;
- criar componentes;
- iniciar qualquer Sprint.

A única tarefa desta etapa é estudar toda a documentação existente.
